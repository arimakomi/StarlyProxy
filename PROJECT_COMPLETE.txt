🎯 ویژگی‌های کلیدی v3.0:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ✨ مدیریت چند Instance
   • نامحدود instance همزمان روی یک سرور
   • هر instance با config، port و process مستقل
   • Auto-assign پورت SOCKS بدون تداخل
   • پشتیبانی از Paqet و GFK به‌طور همزمان

2. 🎨 پنل وب حرفه‌ای
   • Dashboard زیبا با آمار real-time
   • مدیریت کامل instances از مرورگر
   • نمایش لاگ‌های رنگی و live
   • نمودارهای Chart.js برای آمار
   • طراحی responsive و فارسی

3. ⚡ CLI قدرتمند
   • دستورات فارسی و کاربرپسند
   • starlyproxy list/add/start/stop/restart/status/logs/delete
   • Bulk operations (start all, stop all)
   • خروجی‌های رنگی و واضح

4. 💾 Database & Persistence
   • SQLite برای ذخیره configs
   • جداول: instances, stats, logs
   • Query سریع و efficient
   • Auto-cleanup لاگ‌های قدیمی

5. 🔌 REST API کامل
   • تمام عملیات از طریق HTTP
   • GET /api/instances - لیست
   • POST /api/instance/<name>/start - شروع
   • GET /api/instance/<name>/status - وضعیت
   • ... و بسیاری دیگر

6. 🛠️ ابزارهای مدیریتی
   • health_check.sh - بررسی سلامت خودکار
   • backup.sh - پشتیبان‌گیری
   • install.sh - نصب یک-دستوری
   • systemd integration کامل

7. 🏗️ معماری حرفه‌ای
   • Modular design
   • Clean separation of concerns
   • Type hints و docstrings کامل
   • Proper error handling
   • Comprehensive logging

📥 نصب (یک خط!):
   curl -fsSL https://raw.githubusercontent.com/arimakomi/StarlyProxy/main/install.sh | sudo bash

🌐 شروع پنل وب:
   sudo systemctl start starlyproxy-panel
   # دسترسی: http://YOUR_IP:5000

💻 استفاده از CLI:
   sudo starlyproxy add my-proxy paqet client 1.2.3.4:8443 "SecretKey"
   sudo starlyproxy start my-proxy
   sudo starlyproxy status my-proxy
   # پروکسی در 127.0.0.1:1080 فعال است!
