Problem Reported:
   "Installation stops at step [1/9]"
   System: AlmaLinux 8.10

Root Cause:
   - Missing EPEL repository (certbot dependency)
   - Silent errors (>/dev/null 2>&1) hid the problem
   - Package installation failed but script continued
   - python3-devel was missing for RHEL-based systems

Solution Applied (Commit: d0026bd):
   ✅ Install EPEL repository first
   ✅ Make certbot optional (not critical for basic function)
   ✅ Add python3-devel for compilation dependencies
   ✅ Show limited output (first 5 lines) for visibility
   ✅ Use || true to continue even if optional packages fail
   ✅ Separate package installation into logical groups

Before (Line 121):
   yum install -y -q python3 python3-pip git nginx certbot python3-certbot-nginx >/dev/null 2>&1

After (Lines 121-126):
   # Install EPEL first for certbot
   yum install -y epel-release 2>&1 | grep -v "^$" | head -3 || true
   # Install packages
   yum install -y python3 python3-pip python3-devel git nginx 2>&1 | grep -v "^$" | head -5 || true
   # Try certbot (optional, may not be available)
   yum install -y certbot python3-certbot-nginx 2>&1 | grep -v "^$" | head -3 || true

Key Improvements:
   1. EPEL installed BEFORE trying to install certbot
   2. python3-devel added (needed for pip packages with C extensions)
   3. Packages split into critical vs optional groups
   4. Limited output visibility (first few lines only)
   5. || true ensures script continues on non-critical failures
